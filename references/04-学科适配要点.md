# 学科适配要点

同样一节课，语文评的是文本解读与语言实践，数学评的是问题链与思维，英语评的是语言运用情境。用错学科的尺子，评课就成了外行话。

使用方式：先确定学科，取对应卡片；学科不明时用末尾的"通用理科/文科"两套简化版。

---

## 语文

- **专业切口**：文本解读的准确性、语言实践活动、单元要素落实。
- **观察重点**：
  1. 教师对文本的解读是否准确、是否有独到之处（有无误读、浅读）。
  2. 学生是否有真实的语言实践——朗读、批注、表达、写作，而不是只回答"对不对"。
  3. 单元语文要素（如"体会人物心情""学习说明方法"）是否在本课落地。
  4. 文体意识：小说、散文、说明文、古诗的教学路径是否区分。
- **常见问题**：把阅读课上成思想品德课；教师讲读代替学生自读；朗读指导停留在"读出感情"而无具体方法；文本解读超出学生理解水平。
- **追问角度**："这个环节您希望学生练的是哪一项语言能力？""如果要让学生自己发现这个写法，您会删掉哪一步引导？"

## 数学

- **专业切口**：问题链的逻辑递进、算理与算法的关系、思维的可视化。
- **观察重点**：
  1. 问题链是否递进（有没有"一步跨太大"或"原地打转"）。
  2. 算理是否讲透，还是只教算法（"为什么这样算"有没有被追问）。
  3. 学生有没有独立思考的时间，错误有没有被利用。
  4. 变式与迁移设计是否到位。
- **常见问题**：教师包办归纳；难点靠"再讲一遍"；练习量大但层次单一；例题与练习之间缺少过渡。
- **追问角度**："这个追问是想让学生回到算理，还是在检查记忆？""这道变式题和例题的差别，您希望学生自己发现还是您点出来？"

## 英语

- **专业切口**：语言的真实运用、情境的完整性、输入与输出的关系。
- **观察重点**：
  1. 是否有真实的语言运用任务，还是句型操练的堆叠。
  2. 情境是否贯穿，还是导入用完就丢。
  3. 输入量是否足够支撑输出（听读先行）。
  4. 学生开口的时间与质量（有没有"意义交流"而非"机械跟读"）。
- **常见问题**：听说课变成单词句型的重复操练；情境"贴标签"；教师语速过快或中英混杂；输出任务缺少支架。
- **追问角度**："这个情境里，学生必须用英语才能完成任务吗？""最后的口头输出，您给了哪些语言支架？"

## 物理

- **专业切口**：科学探究的真实性、实验与结论的逻辑、物理模型的建构。
- **观察重点**：
  1. 探究是"真探究"还是"验证式演示"（变量是否由学生控制）。
  2. 实验数据是否真实处理（有无"凑数据"）。
  3. 从现象到规律的推理链是否完整。
  4. 物理模型与生活情境的联系。
- **常见问题**：探究步骤由教师全程包办；结论直接给；实验只做演示不让学生动手；公式推导与物理意义脱节。
- **追问角度**："这个变量是学生自己想到要控制的，还是您给定的？""如果实验数据与预期不符，您会怎么处理？"

## 化学

- **专业切口**：宏观—微观—符号三重表征、实验安全与规范、证据推理。
- **观察重点**：
  1. 是否建立宏观现象与微观解释的联系。
  2. 化学方程式/符号表征与实验现象的对应。
  3. 实验操作的规范性与安全意识。
  4. 证据推理过程是否完整。
- **常见问题**：只记现象不解释本质；实验操作由教师代劳；方程式书写与现象脱节；安全提醒流于形式。
- **追问角度**："这个现象您希望学生用微观解释到哪一层？""实验中哪个环节可以让学生自己判断下一步？"

## 生物

- **专业切口**：生命观念、结构与功能相适应、探究实验的设计。
- **观察重点**：
  1. 是否体现"结构与功能相适应"等生命观念。
  2. 实验设计的变量控制与对照设置。
  3. 概念建构是否基于事实证据。
  4. 与生活、健康的联系。
- **常见问题**：概念灌输代替探究；实验只验证不设计；图表信息读取训练不足；生命观念停留在口号。
- **追问角度**："这个概念是学生从数据里推出来的，还是您总结给他们的？""这个对照实验，让学生自己设计会缺哪一步？"

## 道德与法治（政治）

- **专业切口**：价值引领的真实性、议题式教学、理论与生活的结合。
- **观察重点**：
  1. 价值引导是否自然，还是口号式灌输。
  2. 是否有真实议题和两难情境（让学生真正思考）。
  3. 理论观点是否有生活案例支撑。
  4. 学生的表达与思辨空间。
- **常见问题**：结论先行、学生只负责认同；案例陈旧或脱离学生生活；讨论流于表态；价值冲突被回避。
- **追问角度**："这个环节学生有没有可能得出和您不一样的结论？您会怎么接？""这个案例离学生的生活有多远？"

## 历史

- **专业切口**：史料实证、时空观念、历史解释。
- **观察重点**：
  1. 史料是否真实、多元，学生是否真的在读史料。
  2. 时空框架是否清晰（时间轴、地图）。
  3. 历史解释是否有多角度，而非单一结论。
  4. 家国情怀的渗透是否自然。
- **常见问题**：结论灌输，史料只作装饰；时间线混乱；只讲"是什么"不讲"为什么"；情感教育生硬。
- **追问角度**："这段史料学生读出了什么？和您的预设一致吗？""这个历史结论，您给了几种解释路径？"

## 地理

- **专业切口**：区域认知、综合思维、地理实践力、人地协调观。
- **观察重点**：
  1. 地图与图表的使用是否到位（读图、析图、绘图）。
  2. 是否建立"位置—要素—联系"的分析框架。
  3. 案例是否真实、典型。
  4. 人地关系的价值引导。
- **常见问题**：地理课变成"背地图"；只记结论不析原因；图表信息提取训练不足；案例堆砌无主线。
- **追问角度**："这个区域的分析，学生掌握了'从哪几个要素入手'的方法吗？""这张图您希望学生先看什么、后看什么？"

## 科学（小学）

- **专业切口**：探究活动的真实性、证据意识、科学思维启蒙。
- **观察重点**：
  1. 学生是否真的在"做"（观察、测量、记录、讨论）。
  2. 结论是否来自证据。
  3. 材料是否适宜、安全。
  4. 科学词汇的使用是否准确。
- **常见问题**：教师演示代替学生动手；结论教师给；记录表设计粗糙；"科学"上成"常识"。
- **追问角度**："这个结论是学生从记录里得出的，还是您说的？""如果实验结果和课本不一样，您会怎么处理？"

## 信息技术

- **专业切口**：计算思维、任务驱动的真实性、技术操作的规范性。
- **观察重点**：
  1. 任务是否有真实意义（做出来有什么用）。
  2. 是否体现问题分解、抽象、算法等计算思维。
  3. 操作演示与自主实践的配比。
  4. 数字素养与信息安全意识。
- **常见问题**：变成软件操作说明书；任务孤立无情境；学生照抄步骤；缺少调试与出错处理。
- **追问角度**："这个任务学生需要自己拆解哪几步？""程序出错时，您希望学生怎么找到问题？"

## 体育

- **专业切口**：运动负荷、技能学习的进阶、安全教育、全体参与。
- **观察重点**：
  1. 运动密度与强度是否达标（学生实际动起来的时间）。
  2. 技能教学的分解与递进（示范、练习、纠错、巩固）。
  3. 是否人人参与，有无"少数人练多数人看"。
  4. 安全防护与场地器材安排。
- **常见问题**：讲解示范时间过长；练习密度低；只练不纠错；安全提醒缺失。
- **追问角度**："这节课学生实际运动的时间大概多少？""这个动作的错误，您预设了几种纠正方法？"

## 音乐

- **专业切口**：听觉体验、音乐要素感知、审美体验的真实性。
- **观察重点**：
  1. 学生是否真的在"听"（完整聆听的时间）。
  2. 音乐要素（节拍、旋律、力度、音色）是否被感知而非被告知。
  3. 参与形式是否指向音乐本身（律动、演唱、演奏、创编）。
  4. 审美体验是否自然发生。
- **常见问题**：用讲解代替聆听；音乐知识脱离作品；活动热闹但与音乐无关；教师范唱/范奏基本功不足。
- **追问角度**："学生听完这段，能说出什么音乐上的感受？""这个律动活动是帮助学生感受节拍，还是只是在动？"

## 美术

- **专业切口**：视觉感知、造型表现、审美判断、创意实践。
- **观察重点**：
  1. 是否给足观察与感受的时间（看原作、看细节）。
  2. 技法示范是否清晰、可学。
  3. 学生作品是否有个人表达，而非统一临摹。
  4. 评价是否指向审美与创意，而非"像不像"。
- **常见问题**：教师示范后学生照抄；创作时间不足；评价只看像不像；美术课变成手工课。
- **追问角度**："学生的作品里，哪部分是自己的想法？""这个示范是给方法，还是给了一个标准答案？"

## 劳动

- **专业切口**：真实劳动任务、劳动观念、动手实践与安全。
- **观察重点**：
  1. 任务是否真实、完整（有准备、实施、整理）。
  2. 学生动手时间是否充分。
  3. 劳动习惯与安全意识。
  4. 劳动观念（尊重劳动、珍惜成果）的渗透。
- **常见问题**：讲劳动代替做劳动；任务被简化成手工制作；安全与规范缺位；课后无延伸。
- **追问角度**："这个任务学生完整做下来需要哪几步？""劳动成果怎么处理，有没有形成闭环？"

## 学前（幼儿园）

- **专业切口**：游戏化、幼儿主体、经验生长。
- **观察重点**：
  1. 是否以游戏为基本活动形式。
  2. 幼儿是否有自主选择与试错空间。
  3. 师幼互动的回应性（开放式提问、接住幼儿的想法）。
  4. 材料投放的层次性与安全性。
- **常见问题**：教师高控；集体活动时间过长；目标小学化；提问封闭；过渡环节等待过长。
- **追问角度**："这个环节幼儿有哪些选择？""幼儿的回答和您的预设不一样时，您是怎么接的？"

## 学科不明时的两套简化版

### 通用理科（数理化生科信）
看四点：**问题链是否递进、概念/原理是否讲透、学生是否有独立思考和动手时间、检测是否跟得上**。

### 通用文科（语英政史地）
看四点：**材料/文本是否被真正使用、学生是否有表达与思辨空间、价值引导是否自然、单元要素/核心素养是否落地**。

### 通用艺体（音体美劳）
看四点：**学生实际参与/运动/创作的时间、专业示范是否到位、是否人人参与、安全与规范**。
