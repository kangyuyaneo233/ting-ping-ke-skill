# 学段观察量表与评课侧重点

同一节课的"好"，在不同学段标准不同。小学看"学生有没有真正动起来"，高中看"思维有没有真正深下去"。用错学段的尺子，评课就会失真。

本文件提供：通用观察骨架 + 四个学段的差异化观察点 + 各学段好课标准 + 常见问题 + 评课语言建议。

---

## 一、通用观察骨架（四个学段共用）

采用 LICC 课堂观察范式（崔允漷团队）作为检查清单，防止观察遗漏。四个维度、二十个视角：

| 维度 | 视角 | 观察什么 |
|---|---|---|
| **学生学习** | 准备 / 倾听 / 互动 / 自主 / 达成 | 学生课前准备、听讲状态、生生互动、自主学习时间、目标达成证据 |
| **教师教学** | 环节 / 呈示 / 对话 / 指导 / 机智 | 环节衔接、讲解与板书、提问与理答、个别指导、临场应变 |
| **课程性质** | 目标 / 内容 / 实施 / 评价 / 资源 | 目标是否清晰可测、内容是否适切、实施是否匹配目标、评价是否跟上、资源是否有效 |
| **课堂文化** | 思考 / 民主 / 创新 / 关爱 / 特质 | 是否有思考时间、是否允许不同意见、是否有创新空间、是否关注每个学生、课堂是否有个人风格 |

**使用方式**：不必逐条打分，而是把它当"我是不是漏看了什么"的核对表。评课稿里只写有证据支撑的维度。

**与教学评一致性的关系**：LICC 负责"看全"，教学评一致性负责"看准"。先扫一遍 LICC 确认没漏，再用目标—活动—评价的对齐分析抓主要矛盾。

## 二、学前（3—6 岁）

### 观察侧重
1. **活动性**：幼儿是否有充分的身体、操作、表达活动，还是长时间坐着听讲。
2. **游戏化**：是否以游戏为基本活动形式；游戏是"真游戏"（幼儿自主）还是"假游戏"（教师操控每一步）。
3. **生活化**：内容是否来自幼儿的生活经验，能否迁移回生活。
4. **幼儿主体**：幼儿有没有选择权（选材料、选伙伴、选玩法）；教师是否给足自主空间。
5. **师幼互动**：提问是封闭的还是开放的；教师回应是"接住"还是"纠正"。
6. **材料适宜性**：材料是否安全、是否可操作、是否有层次（满足不同发展水平）。
7. **常规与安全**：过渡环节是否顺畅，是否存在安全隐患。

### 好课标准（学前版）
- 幼儿在活动中是主动的、投入的，有笑、有问、有尝试；
- 教师"退得出去"，多数时间是观察者和支持者，不是指挥者；
- 活动目标落在幼儿的经验生长上，而不是落在"教师讲完了"；
- 材料和环境本身在"说话"，不依赖教师反复讲解。

### 常见问题
- 集体教学时间过长，幼儿注意力涣散；
- 教师高控，预设每一步，幼儿没有试错空间；
- 目标小学化（提前教拼音、写字、算术）；
- 提问封闭（"是不是""对不对"），幼儿只需齐答；
- 过渡环节等待过长，秩序靠大声维持。

### 评课语言建议
用"幼儿"作主语，不用"学生"。评价落在"幼儿的经验""幼儿的参与"上，例如：
"在'沉与浮'的探索区，多数幼儿是先试再问，而不是先听教师讲规则——这个顺序值得保留。"

## 三、小学

### 低段（1—2 年级）观察侧重
1. **习惯养成**：倾听习惯、举手发言、书写姿势、物品整理。
2. **直观形象**：是否用实物、图片、动作帮助理解，抽象符号是否给足过渡。
3. **趣味性**：情境是否贴近儿童生活，是否有游戏、儿歌、故事等载体。
4. **表达机会**：是否给每个学生说话的机会，还是只有少数人发言。
5. **节奏**：低段注意力短，环节是否 8—12 分钟一切换。

### 中高段（3—6 年级）观察侧重
1. **思维过渡**：从直观到抽象的过渡是否有支架（图、表、操作）。
2. **合作学习**：小组合作是否有明确分工和任务单，还是"热闹但空转"。
3. **问题意识**：是否鼓励学生提问，教师是否接住学生的问题。
4. **自主学习**：是否有独立阅读、独立思考、独立练习的时间。
5. **目标检测**：新授之后是否有当堂检测，检测是否覆盖不同水平。

### 好课标准（小学版）
- 学生在大部分时间里"有事做"，且做的事指向目标；
- 抽象概念有具体的"落地动作"（操作、画图、举例）；
- 提问有梯度，能照顾到不同水平的学生；
- 有当堂检测，教师能说出"哪些学生还没掌握"。

### 常见问题
- 教师讲得多、学生练得少，一节课学生动笔不足 10 分钟；
- 小组合作流于形式，没有任务单、没有分工、没有汇报；
- 齐答代替个别回答，热闹掩盖差异；
- 情境"为趣而趣"，与教学内容关联弱；
- 评价只有口头表扬，没有指向学习内容的反馈。

### 评课语言建议
多用"学生"作主语，关注"每个学生"而非"全班"。例如：
"这节课的两次小组讨论，第一次有任务单、有分工，第二次只有'讨论一下'——第二次的讨论时间更像是等待时间。"

## 四、初中

### 观察侧重
1. **思维含量**：问题是否有思考价值，是否停留在记忆与复述。
2. **学科方法**：是否体现本学科特有的思维方式（如数学的推理、语文的文本细读、物理的控制变量）。
3. **自主学习**：是否有预习反馈、自主探究、自我评价的环节。
4. **分层与差异**：是否有针对不同水平的任务或追问。
5. **目标达成检测**：检测是否与目标对应，是否当堂反馈。
6. **课堂节奏**：难点是否给足时间，重点是否讲透。

### 好课标准（初中版）
- 主干问题有思维梯度，能引发学生"想一会儿"；
- 学生的回答被当作资源使用，而不是只被判断对错；
- 学科方法显性化，学生知道"这类问题该怎么想"；
- 目标达成有可观察的证据（练习正确率、学生表述、板演）。

### 常见问题
- 问题链断裂，问题之间没有逻辑递进；
- 教师包办归纳，学生只负责"填空"；
- 难点处理靠"再讲一遍"，而不是换一种表征；
- 检测缺位，讲完就进入下一环节；
- 学生活动有"热度"无"深度"，讨论停留在表面。

### 评课语言建议
关注"思维发生了什么"。例如：
"第二个追问'为什么这里不能直接约分'，把学生从操作拉回到了算理——这一问是整节课思维含量最高的地方。"

## 五、高中

### 观察侧重
1. **学科核心素养**：是否指向本学科核心素养的具体表现，而不是知识点罗列。
2. **深度学习**：是否有结构化建构、迁移应用、批判性思考。
3. **真实情境**：情境是否真实、复杂、有探究空间，还是"伪情境"（只为引出知识点）。
4. **知识结构化**：是否帮助学生建立知识网络，而不是碎片记忆。
5. **学生主体与元认知**：学生是否有反思"我怎么想的"的机会。
6. **高考/学业质量关联**：是否对接学业质量水平要求（但不应沦为刷题）。

### 好课标准（高中版）
- 一节课有一条清晰的"思维主线"，学生能说出"今天我们是怎样一步步想明白的"；
- 情境真实且贯穿，不是导入用完就丢；
- 学生的错误被当作教学资源，教师能追问到错误的根源；
- 素养目标有落点，不是贴在教案上的标签。

### 常见问题
- 情境"贴标签"，与知识关联牵强；
- 容量过大，赶进度，学生没有思考时间；
- 教师讲得精彩，学生学得被动；
- 素养目标空转，实际仍在训练解题套路；
- 缺少知识结构化，学生记住的是零散结论。

### 评课语言建议
关注"素养有没有落地"。例如：
"这节课用本地水质数据贯穿始终，最后的迁移任务让学生用同一套方法分析另一组数据——素养目标不是写在教案上，而是在任务里被用出来了。"

## 六、跨学段通用：一节课的"体检表"

无论哪个学段，评课前先过一遍这 8 问，能快速定位主要矛盾：

1. 这节课的目标，学生离开教室时能带走什么？（一句话说清）
2. 目标是否可观察？课堂上什么行为能证明达成？
3. 主要活动是否都指向目标？有没有"目标外活动"？
4. 难点是否给了足够时间和支架？
5. 学生的错误和差异，被看见了吗？被用上了吗？
6. 有没有当堂检测？检测结果教师当堂知道吗？
7. 学生有没有自己思考和表达的时间？（不是齐答）
8. 这节课最"值钱"的一个瞬间是什么？为什么值钱？

第 8 问的答案，往往就是评课稿里最该写的那个亮点。
