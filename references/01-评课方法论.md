# 评课方法论

本文件解决一个问题：**评课凭什么站得住**。不是靠经验多、资历老，而是靠框架、证据和判断逻辑。

---

## 一、先看传统听评课的病根

崔允漷团队对传统听评课的诊断是"三重三轻"：

| 病根 | 表现 |
|---|---|
| 重教师表演，轻学生学习 | 笔尖追着教师动作（板书工整吗、语言生动吗、环节流畅吗），没人记录"第三排靠窗学生皱眉了几次" |
| 重经验判断，轻数据支撑 | "气氛活跃""目标基本达成"之后就没有然后了 |
| 重个体感悟，轻团队协作 | 一个人听完一个人评，没有分工观察，没有共享规则 |

由此产生三类"走空"的评课：

1. **形容词评课**：教态自然、气氛活跃、基本功扎实——抽掉课题能贴到任何一节课上。
2. **表扬式评课**：只说好话，问题用"如果……会更好"轻轻带过，教研组听完没有可改的东西。
3. **审判式评课**：把人当对象，"这个老师驾驭不了""学生基础太差"，评完关系紧张、问题没解决。

**本 Skill 的立场**：从"评判"转向"诊断"。评课不是给课打分，而是**找到一两个值得深挖的教学决策，把课评透**。

## 二、核心框架（按使用场景选）

### 2.1 教学评一致性（首选主轴）

新课标语境下最站得住的评课切口。操作链是"关键三问"：

1. **目标是什么**？（学生离开教室能带走什么，一句话说清）
2. **如何判断目标达成**？（什么行为证据能证明）
3. **如何达到**？（活动与支架是否指向这个证据）

每一问对应评课稿的一个部分：第 1 问→总评与目标审读；第 2 问→评价设计检查；第 3 问→环节与活动分析。

**为什么要用这条主轴**：它把"课好不好"这个模糊问题，拆成了三个可回答的具体问题，且直接对接课程标准，不是空谈理念。

### 2.2 LICC 课堂观察（看全的检查表）

崔允漷团队的课堂观察范式，四维度、二十视角、六十八观察点。作用不是打分，而是**防止漏看**。

| 维度 | 视角 |
|---|---|
| 学生学习 | 准备 / 倾听 / 互动 / 自主 / 达成 |
| 教师教学 | 环节 / 呈示 / 对话 / 指导 / 机智 |
| 课程性质 | 目标 / 内容 / 实施 / 评价 / 资源 |
| 课堂文化 | 思考 / 民主 / 创新 / 关爱 / 特质 |

两个常被忽略但价值最高的视角：
- **教师教学的"机智"**：教学设计做了哪些临场调整、为什么调、效果如何；突发事件怎么处理。这里往往藏着真亮点。
- **课堂文化的"关爱"**：特殊学生是否被关注、座位安排是否得当、沉默的学生有没有被叫到。

### 2.3 五维评课"手术刀"（写深度的框架）

来自毕小芬《评课的五把"手术刀"》，适合需要"评透"而不是"评全"的场合：

1. **目标维度**：目标是否清晰、可测、贯穿全程
2. **内容维度**：教材解读是否准确，是"教教材"还是"用教材教"
3. **学生维度**：学习是否真正发生，学生是否在课堂中央
4. **教学行为维度**：提问、理答、活动组织、时间分配
5. **课堂生成维度**：预设之外发生了什么，教师接住了没有

**使用要点**：不必五个维度都写。挑一两个本节课最值得追问的点深挖，其余一笔带过。评课的价值密度取决于深度，不取决于覆盖面。

### 2.4 四步诊断法（把"评判"变成"追问"）

这是本 Skill 亮点与建议的核心写法：

**说现象 → 追决策 → 给判断 → 嵌理论**

1. **说现象**：时间、人物、行为、反应，四个要素缺一不可。"第 12 分钟，教师让小组讨论，第三组四人中只有一人说话，其余三人低头记录。"
2. **追决策**：教师在这里做了什么选择，选择的逻辑可能是什么。"教师选择了不给任务单、只口头说'讨论一下'。"
3. **给判断**：不是对错二元，而是"这个决策在什么条件下成立、在什么条件下失效"。"口头指令在任务简单时成立；但本题需要比较三种解法，没有任务单，讨论容易退化为复述。"
4. **嵌理论**：理论不是贴在开头，而是在分析完成后自然长出来的解释工具。"这对应'小组合作需要可分解的任务和共享的规则'——缺了后者，合作就变成优等生的单向输出。"

### 2.5 五线框架（梳理环节时的检查线）

万建勇提出，看一节课可以顺着五条线走：

- **知识线**：知识是怎么组织的，有没有结构化
- **能力线**：训练了哪些可迁移的能力
- **素养线**：指向哪条核心素养的具体表现
- **活动线**：学生做了什么，活动的思维含量如何
- **问题线**：问题链是否递进，问题之间有没有逻辑

梳理环节表时，用这五条线检查"有没有断线"——断在哪里，往往就是建议的落点。

## 三、证据从哪来

评课的底气来自证据。证据分四级（魏建斌"四级编码法"的简化版）：

| 级别 | 证据类型 | 例子 |
|---|---|---|
| 一级 | 可量化记录 | 提问 18 次，其中 12 次是封闭式；学生独立练习 6 分钟 |
| 二级 | 行为片段 | 学生 A 连续两次举手未被叫到，第三次不再举手 |
| 三级 | 原话 | 学生说"因为它是封闭的，所以不能算周长" |
| 四级 | 作品/痕迹 | 板演出现两种不同解法；练习本上 5 人错误集中在同一处 |

**写评课稿时，每个判断后面尽量挂一条证据。** 没有证据的判断，要么删掉，要么降级为"存疑，待确认"。

**伪证据要警惕**：
- "课堂气氛活跃"——可能是齐答造成的假热闹
- "学生参与度高"——可能只有前两排
- "目标基本达成"——没有检测就没有达成

## 四、评课的政策依据（引用时用得上）

1. **《基础教育课程教学改革深化行动方案》**（教材厅函〔2023〕3 号）第 10 条：要求"建立健全校长、教学管理人员和教研员听课评课制度，明确教学评价要素和要求"。——这是"听评课是制度性动作"的直接依据。
2. **《教育部关于加强和改进新时代基础教育教研工作的意见》**（教基〔2019〕14 号）：提出"在课程目标引领下的备、教、学、评一体化的教学格局"，要求教研员开展听评课和说课活动。
3. **《义务教育课程方案和课程标准（2022 年版）》**：各学科课程标准均含"评价建议"部分，是学科评课对标课标的入口。

**引用原则**：政策是背景，不是论据。不要在评课稿里大段抄政策原文，只在需要说明"为什么这样评"时点一句。

## 五、常见误区自查表

写完评课稿，对照这张表过一遍：

| 误区 | 自查问题 |
|---|---|
| 万能话 | 这句话换一节课还能用吗？能→删 |
| 无证据判断 | 每个"好"和"不好"后面有证据吗？ |
| 只评不追 | 有没有把至少一个判断转成对教师的追问？ |
| 面面俱到 | 是不是五个维度都写了但都不深？砍到 3 条以内 |
| 建议不可行 | 建议里的动作，另一个老师明天能照着做吗？ |
| 审判语气 | 有没有"这个老师不行"这类人身评价？ |
| 只看到教师 | 学生的反应、差异、沉默被记录了吗？ |
| 脱离课标 | 素养目标是真落点了，还是贴的标签？ |
