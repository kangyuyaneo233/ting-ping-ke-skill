## 一、解决什么问题

**真实痛点**：听完一节课，速记本上是这样的——

> 导入用绳子绕硬币，学生估 2.5 和 6，差好多……练习讲 3 题，学生齐答……后排有个男生玩尺子……

到了教研组会上，这些鲜活的观察变成三句场面话：**"教态自然、气氛活跃、建议多关注学困生"**。

问题不在教师不会说话，而在**从"速记"到"评课稿"这一步缺少方法**：不知道怎么把观察变成证据，不知道怎么把证据变成有机制的分析，不知道怎么把分析变成能落地的建议。

**这个 Skill 就补这一步。**

## 二、产出什么

一份结构化评课稿，含七个部分：

1. **一句话总评**——结论先行
2. **教学环节梳理**——环节/时长/师生活动/目标指向/观察证据 表
3. **亮点**——每条按"现场→机制→证据→可迁移"写，说清"为什么有效"
4. **建议**——每条按"现状→影响→具体改法→预期"写，必须能明天就改
5. **可追问的问题**——四层递进：事实澄清→设计意图→学生视角→改进假设
6. **目标达成度速评**（可选）
7. **使用说明**——教研素材定位、脱敏声明

**三种输出模式**，根据输入自动切换：
- 模式 A：有速记 → 评课稿
- 模式 B：只有设计 → 教学设计审读意见（不伪装成课堂实录）
- 模式 C：两者都有 → 对照式评课（预设 vs 实施）

## 四、怎么用

### 在支持 Skill 的 AI 平台上
把本目录作为 Skill 上传/加载，然后直接说：

> "我是小学三年级数学老师，刚听完一节《周长的认识》。这是我没整理的速记：[粘贴]。帮我写一份教研组能用的评课稿。"

### 作为提示词模板使用
如果平台不支持 Skill，可以把 `SKILL.md` 全文 + 对应学段的 `references/02` + 对应学科的 `references/04` 一起粘贴给 AI，作为系统提示。

### 建议补充的信息（有则更好，无则用通用框架）
学段、学年、学科、课题、课型、听课时长、评课立场（常规教研/赛课点评/青年教师指导/推门课反馈）。

## 六、安全与合规

- **学生信息脱敏**：姓名→学生A/学生B，班级→某班，学校→某校；成绩、家庭情况一律不进入评课稿。
- **不编造**：未观察到的课堂细节不写，推断标注"（推断）"。
- **不评人**：评课对课不对人，不输出对教师能力、态度的人身评价。
- **定位清晰**：产出是教研讨论素材，不替代教师自评，不作为考核的唯一依据。
- 遵循《个人信息保护法》对未成年人信息的最小必要与脱敏要求。

## 七、适用边界

- ✅ 中小学、幼儿园各学段的公开课、推门课、教研课、赛课、师徒听课
- ✅ 听课速记、课堂实录、教学设计、语音转写稿
- ⚠️ 材料过短（<100 字）时，只输出"信息缺口清单"，不硬写
- ⚠️ 只有教学设计时，输出"审读意见"而非"评课稿"
- ❌ 不适用于：学生评价、教师绩效考核、职称评审等需要量化打分的正式场景
