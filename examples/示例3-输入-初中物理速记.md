# 示例 3：输入样例 —— 初中物理听课速记

> 使用场景：初中物理八年级《牛顿第一定律》，教研组推门课。
> 特点：**速记内部存在时间线矛盾**（"2 组做完就下课铃"与"还有 5 分钟练习"对不上），用于测试 Skill 会不会强行消解矛盾。
> 说明：本样例用于冷启动测试——执行者只拿到 SKILL.md，不给任何参考文件。

---

## 原始速记

```
14:05 八年级3班 物理 牛顿第一定律 陈老师
导入：演示推课本，松手后课本停下。问"力是维持运动的原因吗"。
学生说"是"。老师说"真的吗？我们来看看"。放了伽利略斜面实验视频（3分钟）。
新授：讲牛顿第一定律内容，板书"一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态"。
强调"没有受到力"不等于"不受力"，举了静止在桌面的书。
学生问"那为什么推一下会动"，老师答"因为推力大于摩擦力"。
实验：斜面小车实验，讲控制变量，学生分组做，2组做完就下课铃了。
练习：只做了1道题，老师讲完。
总结：没有总结，直接下课。

观察：
- 提问12次，其中8次是"对不对""是不是"
- 学生分组实验时，老师只巡视了前3组，后2组学生一直在聊天
- 板书：标题+定律内容+一个"注意"框
- 时间：导入8分钟，新授12分钟，实验15分钟，练习5分钟
- 后排有学生说"听不懂"
```

---

## 这份速记的设计意图（测试点）

| 测试点 | 速记中的体现 | 考察 Skill 的什么能力 |
|---|---|---|
| 无教学目标 | 全篇没有写教学目标 | 第六节能否正确省略、"指向的目标"列能否标"未提供" |
| 速记内部矛盾 | "2 组做完就下课铃" vs "练习 5 分钟" | 是否强行消解矛盾，还是并列 + 标"待确认" |
| 缺时间戳的观察 | "后排有学生说'听不懂'"（无时间） | 四要素不全时，能否降级为追问而非丢弃或补编 |
| 封闭式提问 | 12 次提问里 8 次封闭 | 能否给出可操作的替换做法 |
| 巡视覆盖不足 | 只巡视前 3 组，后 2 组聊天 | 能否把现象诊断为"任务未落到人"而非"纪律问题" |
| 半对半错的做法 | "因为推力大于摩擦力"接住了提问，但解释不完整 | 能否拆成"亮点（课堂文化）+ 建议（学科内容）" |

→ 对照 `示例3-输出-初中物理.md` 看 Skill 的实际处理。
