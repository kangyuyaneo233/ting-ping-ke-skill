# 示例 1：输入样例 —— 听课速记（现场记录原文）

> 使用场景：教研组推门课，听课教师现场速记，未做整理。
> 特点：碎片化、口语、时间戳不全、有缩写、有漏记——**这才是真实的速记**。

---

## 原始速记

```
9:00 三年级2班 数学 周长的认识 张老师
导入：绳子绕硬币，让学生估周长。生1说2.5厘米，生2说6厘米，差好多。
张老师说"先别急着改，我们量一量"，让全班用尺子量，量完有人喊"才3厘米多"。
讲定义：板书"封闭图形一周的长度"。举了长方形、三角形。
练习：发了练习纸4道题。讲第1题，讲第2题，讲第3题。学生齐答"对""是"。
第4题没讲完下课了。
总结2分钟：问"今天学了什么"，学生答"周长"。张老师说"对，封闭图形一周的长度"。

观察：
- 提问基本都是齐答，个别叫了2个学生（前排）
- 后排靠窗有个男生一直在玩尺子
- 小组没有，全程教师讲
- 板书：左边标题，右边长方形三角形图，标了周长线
- 时间：导入10分钟，讲定义8分钟，练习15分钟，总结2分钟

自评（张老师课后说）："导入挺好，就是练习时间不够，下次要压缩导入。"
```

---

## 这份速记的信息特征

| 特征 | 说明 |
|---|---|
| 有环节名 | 导入、讲定义、练习、总结 |
| 有时间戳 | 9:00 开始，各环节有估算时长 |
| 有学生原话 | "才3厘米多"、""对""是" |
| 有具体细节 | 2.5 vs 6 厘米的差异、"先别急着改"的处理 |
| 有观察补充 | 后排玩尺子的男生、提问方式、板书结构 |
| 有教师自评 | 张老师自己的反思（可作为追问的切入点） |
| 缺口 | 第4题内容不明、学生总数不明、具体班级人数不明 |

→ 这些缺口对应评课稿里"（推断）"的标注和"需要补充的信息"。
